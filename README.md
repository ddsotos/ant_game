# アリ進化ゲーム v0.16 プロトタイプ

実在するアリの適応を進化列へ積み、目先の繁栄、常に起こる問題への防御、将来の環境変化への最適化を競わせる5ラウンドの実験ゲームです。

現在の版では、通常環境から4枚、専用の最終環境から1枚をseedで選び、最初から公開します。ラウンド5には必ずタグ8級の最適化と強い問題補正を持つ最終環境が置かれます。各ラウンドの開始時には「襲撃」と「衛生」を振り、カードの起動、防御、タグ構築を考えて対応します。問題減点は今ラウンドの繁栄から先に引き、残りへ小型1～超大型4の倍率を掛けます。

## ブラウザで遊ぶ

追加パッケージやフロントエンドのビルドは不要です。PowerShellでリポジトリへ移動し、次を実行してください。

```powershell
python -m ant_game.webapp
```

日本語のゲーム画面が `http://127.0.0.1:8000/` で開きます。終了するには、起動したPowerShellで `Ctrl+C` を押してください。ブラウザが自動で開かなければ、上のURLを手動で開いてください。

全108枚の形質カードは `http://127.0.0.1:8000/cards` で確認できます。ゲーム画面右上の「カード一覧」からも別タブで開けます。名前検索と、タグ・役割による絞り込みに対応しています。

画面には次の情報が表示されます。

- 5ラウンド分の環境予報と、各環境の複数最適化パターンまたは問題強化
- 襲撃・衛生の生の出目、環境補正、対応シールド
- サイズ、公開カード、手札、3本の進化列
- カード自身のタグと、自身を除いた起動条件
- 配置直後に起動できる列（緑）と、必要タグがあと1の列（黄）
- 難しいカードの条件未達時に使える弱効果
- 繁栄加算、指数減点、最適化失敗時半減の精算内訳
- 条件達成時の次ラウンド保持、盤面タグ加点、形質固有の追加効果
- 手札を伏せ、翌ラウンド以降に毎ラウンド繁栄2へ変換する貯蔵カード（貯蔵しない選択も可能）
- 遺伝子発現を切り替えて同列下段カードを手札へ戻す効果
- 移住・広域探索により次ラウンドの公開候補を増やす効果
- 進化列に表示される、開始分・カード起動・貯蔵・タグ加点・問題差引・倍率後得点の内訳
- 最大2個の印刷タグと、単タグカードに与えられた強めの起動効果
- 化学・形態を中心に追加された実在アリ由来の20枚

## 基本操作

各ラウンドでは次の順に操作します。

1. サイズを選ぶ。
2. 公開された6枚からカードを保持する。各ラウンド1回、保持上限を1枚減らして候補を2枚追加で見ることもできる。
3. 手札を列の先頭へ置く、または先頭直下へ支援として置く。
4. 条件を満たす列の先頭カードを起動する。
5. 任意のタイミングでラウンドを精算する。

大型ほど繁栄倍率は高くなりますが、保持できるカードが減ります。支援カードと覆われたカードは効果を使えませんが、タグを供給し続けます。
保持カードの選択中も現在の手札を確認できます。操作を誤った場合は「一手戻す」で直前の成功した操作へ戻れます。画面上部の「環境データ」から、ChatGPTへそのまま渡せる現行の環境・最適化・問題ルールJSONをダウンロードできます。

## デバッグ用CLI

```powershell
python -m ant_game.cli --seed 42
python -m ant_game.cli --list-disasters
```

ブラウザ版が人間向けの標準画面です。CLIはゲームロジック確認用に残しています。

## テスト

```powershell
python -m pytest -q
```

`GAME_DESIGN.md` が現行ルールの正本です。過去の実験結果は `PLAYTEST_LOG.md`、採用判断は `DECISIONS.md`、アリ題材と出典は `ANT_RESEARCH_CATALOG.md` に記録しています。
